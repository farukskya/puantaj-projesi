# Puantaj & Vardiya Takip Sistemi

Kurum bünyesindeki personel vardiya düzenini, organizasyon yapılarını ve günlük puantaj kayıtlarını dijital ortamda yönetmek amacıyla geliştirilmiş full-stack web uygulaması.

## 🛠️ Teknolojiler

- **Backend:** Java, Spring Boot, Spring Data JPA
- **Frontend:** Angular, TypeScript, SCSS
- **Veritabanı:** PostgreSQL / MSSQL
- **Sürüm Kontrolü & Deploy:** Git, GitHub, Vercel

## 🚀 Öne Çıkan Özellikler

- **Personel Yönetimi:** Personel ekleme, güncelleme ve organizasyon birimlerine atama.
- **Vardiya & Puantaj Takibi:** Günlük vardiya defteri tutma, devam/devamsızlık ve puantaj kayıtları oluşturma.
- **Organizasyon Yapısı:** Şirket içi birim ve departman hiyerarşisini tanımlama.
